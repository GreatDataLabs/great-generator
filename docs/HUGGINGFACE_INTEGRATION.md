# Hugging Face Integration

Great Generator integrates with the Hugging Face ecosystem without making Hugging Face packages required for the base install.

The integration helps you:

- convert generated pandas DataFrames to Hugging Face `Dataset` objects
- convert relational table dictionaries to `DatasetDict` objects
- generate Hugging Face-style dataset cards for synthetic datasets
- prepare local dataset artifacts that users may publish manually if appropriate

Great Generator is an independent open-source project. It is not part of Hugging Face Transformers and is not officially endorsed by Hugging Face.

## Installation

Base install:

```bash
pip install great-generator
```

Hugging Face Dataset helpers:

```bash
pip install "great-generator[hf]"
```

Transformers advisor support:

```bash
pip install "great-generator[transformers]"
```

Full optional Hugging Face stack:

```bash
pip install "great-generator[hf-full]"
```

## Convert pandas output to a Hugging Face Dataset

```python
from great_generator import generate_from_schema, to_hf_dataset

schema = "customer_id int, email string, signup_date date, account_status string"
df = generate_from_schema(schema, rows=1000, seed=42)

dataset = to_hf_dataset(df)
```

This conversion is local. It does not upload anything and does not require a Hugging Face token.

## Convert relational output to DatasetDict

```python
from great_generator import generate_relational, to_hf_dataset_dict

relationships = ["customers.customer_id -> orders.customer_id"]
tables = {
    "customers": "customer_id int, customer_name string, email string",
    "orders": "order_id int, customer_id int, order_date date, order_total double",
}

data = generate_relational(
    tables=tables,
    relationships=relationships,
    rows={"customers": 1000, "orders": 5000},
    seed=42,
)

dataset_dict = to_hf_dataset_dict(data)
```

Each table becomes one named entry in the returned `DatasetDict`.

## Generate dataset cards

```python
from great_generator import generate_hf_dataset_card

card = generate_hf_dataset_card(
    dataset_name="synthetic-retail-star-schema",
    domain="retail",
    row_counts={"dim_customer": 10000, "fact_sales": 1000000},
    seed=42,
    intended_use=["data engineering demos", "query testing"],
    not_intended_use=["production analytics", "privacy anonymization claims"],
    limitations=["Synthetic data only", "Does not represent real customers"],
)

with open("README.md", "w", encoding="utf-8") as handle:
    handle.write(card)
```

Every generated card includes this notice:

> This dataset is synthetic. It was generated by Great Generator. It is not production data, and it is not an anonymized, masked, or de-identified copy of production records.

Do not claim privacy guarantees for generated datasets.

## Publishing to Hugging Face Hub manually

Great Generator does not upload datasets automatically in v1. A safe workflow is:

1. Generate data locally.
2. Review row counts, schema, examples, and limitations.
3. Generate a dataset card.
4. Use Hugging Face's standard CLI or Python APIs to publish if appropriate.
5. Keep the dataset private unless you intentionally want it public.

Example manual workflow outside Great Generator:

```bash
huggingface-cli login
# Review your files first, then publish using Hugging Face tooling.
```

Do not paste tokens into notebooks. Use the standard Hugging Face login flow or environment configuration.

## Responsible synthetic dataset documentation

A good synthetic dataset card should include:

- synthetic data notice
- generation method
- schema summary
- row counts
- seed and generation settings, when available
- intended use
- not intended use
- limitations
- license
- regeneration instructions
- project link or citation

## Limitations

- Hugging Face integrations are optional.
- Conversion helpers currently focus on pandas DataFrames.
- Publishing to the Hub is intentionally manual in v1.
- Great Generator does not anonymize, mask, de-identify, or transform production records.
- Generated data may be useful for tests, demos, tutorials, and experiments, but it should not be treated as production evidence.
