# Release History Evidence

The authoritative human-readable release history is maintained in [`CHANGELOG.md`](../CHANGELOG.md). Package metadata is defined in [`pyproject.toml`](../pyproject.toml), and signed or immutable release artifacts should be linked here when available.

When recording a release, include its version, date, Git tag, commit, PyPI URL, artifact hashes, workflow run, and release notes. Do not mark `Unreleased` work as published.
