## Technical contribution under evaluation

Great Generator investigates converting normalized data contracts and supported SQL workload requirements into deterministic synthetic datasets with measurable predicate, join, boundary, and NULL-semantics coverage.

## Claim boundaries

The repository does not claim that the underlying testing methods are unprecedented. Prior work exists in constraint-based database testing, property-based testing, query fuzzing, and SQL test-data generation. Any claim of technical distinction must cite both comparative analysis and executed evidence.
